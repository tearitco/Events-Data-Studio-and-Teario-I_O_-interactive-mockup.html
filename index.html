🧮 Why a page can’t run every tick 🟩 FACT + 🟨 ESTIMATE

Measured: every page run launches several processes (sh, bash, prisc); 5 runs in 24 s used 4.5% of a core. I extrapolate linearly from that one number, so treat the result as a rough estimate.
